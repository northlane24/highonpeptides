# HighOnPeptides

**The peptide industry. Decoded.**

An independent, evidence-first science and industry information website.

## Run locally

1. Install Node.js 20 or later.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deploy
Import this repository into Vercel and use the default Next.js settings. Build command: `npm run build`.\n

Editorial principles: distinguish approved therapies from investigational compounds; link sources for research and news; make evidence limitations clear; do not provide dosing, sourcing, or personalized medical advice.
